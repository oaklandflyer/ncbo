NCBO Admin

Local tool — not published with the site. Run it from your own copy of the repo.

Content & photos

Edit site text, clubs, team, FAQs and news, upload and crop photos, and commit the changes straight to GitHub.
One key, and it is yours. This tool is not published — it runs from your local copy of the repo, so there is no sign-in and no URL to find. What lets anyone change the live site is a GitHub personal access token, entered on the Content page and sent straight from your browser to GitHub. Nothing here stores it. See admin/README.md.

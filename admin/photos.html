Token & security notes
Create a fine-grained personal access token at github.com/settings/personal-access-tokens, scoped only to the ncbo repository, with Contents: Read and write permission and nothing else. The token is only ever sent directly from your browser to api.github.com — this page has no server of its own and nobody else sees it. Each save here is a real commit to the main branch, which GitHub Pages deploys automatically.
